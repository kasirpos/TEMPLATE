## 🎯 Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🛒 Kasir / POS | Transaksi cepat, multi-item, split bill |
| 📊 Dashboard | Omset harian, bulanan, grafik penjualan |
| 📦 Manajemen Menu | CRUD produk, kategori, HPP, margin |
| 🎟️ Kupon Diskon | Persen / nominal, batas penggunaan |
| 🖨️ Cetak Struk | Thermal 58mm, struk pelanggan & dapur |
| 💰 Kas & Petty Cash | Modal awal, pengeluaran, tutup shift |
| 📈 Laporan | Omset, HPP, laba, margin per produk |
| 🌙 Dark Mode | Auto-switch, customizable accent |
| ☁️ Cloud Sync | Google Spreadsheet + Apps Script |
| 📱 Responsive | Mobile, tablet, desktop |
